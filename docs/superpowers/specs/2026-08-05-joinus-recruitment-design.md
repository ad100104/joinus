# 真知招聘页优化设计

## 目标

把现有加入我们页面升级为面向候选人的 AI Native 招聘体验：保留现有全屏首图和品牌导航，同时完整表达真知的组织方式、工作原则、岗位机会与投递路径。

## 信息架构

1. **Hero 首屏**
   - 使用现有 `images/hero-bg.jpg` 作为全屏背景。
   - 保留主标题“和伟大的人，做伟大的 Agent”。
   - 增加“真知是一家 AI Native 公司”与使命副文案。
   - 提供“查看岗位”锚点按钮，指向职位区。

2. **我们是谁**
   - 介绍 HaiTun 是真知的大脑、伙伴，而非单一工具。
   - 以三项短内容说明 Agent 协作、马赛克式组织、TPMF 小组独立作战。

3. **我们怎么工作**
   - 展示 73 原则、TODO 驱动、先问 Agent、打仗心态、空杯心态。
   - 73 原则作为视觉主记忆点，其余原则以编号信息块排列。

4. **招聘岗位**
   - 左侧为四个岗位导航，右侧为当前岗位详情。
   - 默认展示 Agent 开发方向实习生。
   - 每个岗位详情包含方向摘要、职责、基本要求、加分项和岗位标签。
   - 使用原生 JavaScript 切换，不引入新框架或依赖。
   - 小屏幕下岗位导航转为可横向滚动的标签栏，详情单列显示。

5. **投递闭环**
   - 集中展示邮箱、HR 电话、邮件标题格式和材料要求。
   - 邮箱使用 `mailto:hr@genuineknowledge.cn`，电话使用 `tel:15606135997`。
   - 明确“不看学历，看成果”的筛选倾向。

6. **Footer**
   - 保留现有品牌标识、主站链接和版权信息。

## 视觉与交互

- 继承现有蓝色品牌色，但用米白、深墨色和青绿色强调层次，避免页面只呈现单一蓝色。
- 采用细边框、轻阴影和不超过 8px 的圆角，减少装饰性卡片堆叠。
- 使用固定顶部导航、平滑锚点滚动和岗位切换动效。
- 所有交互控件提供键盘可访问的按钮语义和清晰焦点状态。
- Hero 在桌面与移动端均保持首图可见，并让下一段内容露出一部分。

## 数据与实现边界

- 岗位文案直接以内联 JavaScript 数据对象维护，便于切换和后续编辑。
- 不接入后端、表单提交或外部 API；投递动作通过系统邮件/电话客户端完成。
- 仅修改 `index.html` 与 `css/style.css`，必要时在 `index.html` 内加入轻量脚本。

## 验证标准

- 桌面宽度下首屏、理念区、岗位切换区和投递区层次清晰，无文字溢出或遮挡。
- 移动宽度下导航、岗位标签、详情内容和投递按钮均可使用，无横向页面溢出。
- 四个岗位均可切换，切换后标题、职责、要求和加分项同步更新。
- 邮箱和电话链接可被浏览器正确识别。
- 页面可直接打开或通过任意静态服务器运行，不依赖构建步骤。
